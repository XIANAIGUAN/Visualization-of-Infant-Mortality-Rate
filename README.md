# 婴儿死亡率：一场本可避免的全球危机

这是一个交互式数据可视化项目，用于探索全球婴儿死亡率的分布、变化趋势及其与其他社会经济指标的关系。

## 🌐 在线访问

**GitHub Pages 地址**: https://xianaiguan.github.io/Visualization-of-Infant-Mortality-Rate/

## 项目简介

本项目使用 D3.js 构建了一个多视图协同的可视化系统，包含：
- **全球地图视图**：交互式世界地图，支持缩放、平移、按地区筛选
- **散点图**：探索婴儿死亡率与其他指标的相关系数
- **热力图**：按地区比较两个指标的排名差异
- **雷达图**：多维度展示选定国家的情况
- **数据表格**：可排序的详细数据

## 数据来源

- [世界银行开放数据平台](https://data.worldbank.org/) — 婴儿死亡率及其他社会经济指标数据

## 技术栈

- D3.js v7（内联于html文件）
- TopoJSON（地图数据内联）
- 纯前端实现，通过 GitHub Pages 部署
